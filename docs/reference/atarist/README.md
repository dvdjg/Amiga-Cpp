# Referencia Atari ST (futura)

Área de documentación de programación, técnicas y hardware para **Atari ST**
(variante STE/STe). Aún no hay contenido; cuando se porten demos del engine a
esta plataforma, la referencia técnica se documentará aquí:

```
docs/reference/atarist/
├── README.md          → este índice
├── hardware/          → chipset Atari ST (Shifter, blitter, DMA, sound)
└── techniques/        → técnicas de programación específicas
```

La estructura de demos por plataforma (dónde irían las demos Atari ST) está en
`docs/STRUCTURE.md` §4 (`demos/atarist/`), y la documentación de referencia
general en `docs/STRUCTURE.md` §10.
