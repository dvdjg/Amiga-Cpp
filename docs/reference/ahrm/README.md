# Amiga Hardware Reference Manual (AHRM) — 3.ª edición

Fuente primaria de hardware del engine. Cubre OCS/ECS/AGA y A3000: registros
custom (`BPLCONx`, `DDF*`, `DIW*`, `BPLxPT`, `DMACON`, `INTENA`, `BLT*`,
`SPR*`, `AUD*`), timing de vídeo/DMA y apéndices de registros.

## Cómo usar

- Consultar un registro o bit: apéndice A (orden alfabético) o B (orden por dirección).
- Entender un mecanismo (copper, playfield, sprite, blitter, audio, interrupciones): capítulos 1–8.
- Matriz OCS/ECS/AGA: apéndice C.
