# Referencia Megadrive (futura)

Área de documentación de programación, técnicas y hardware para **Sega
Megadrive (Genesis)**. Aún no hay contenido; cuando se porten demos del engine a
esta plataforma, la referencia técnica se documentará aquí:

```
docs/reference/megadrive/
├── README.md          → este índice
├── hardware/          → chipset Megadrive (VDP 68000, Z80, PSG, FM, DMA)
└── techniques/        → técnicas de programación específicas
```

La estructura de demos por plataforma (dónde irían las demos Megadrive) está en
`docs/STRUCTURE.md` §4 (`demos/megadrive/`), y la documentación de referencia
general en `docs/STRUCTURE.md` §10.
