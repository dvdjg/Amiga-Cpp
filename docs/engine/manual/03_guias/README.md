# Guías (how-to)

Recetas **por tarea**: cómo conseguir un objetivo concreto con el engine. Cada guía es corta,
muestra el camino recomendado y **cita el fuente**.

| Guía | Objetivo |
|---|---|
| animar_scroll_y_parallax.md | Fondo con scroll (tiras/corkscrew) + capas de parallax. |
| colisiones_y_deteccion.md | Colisión por caja/máscara y consulta de tiles. |
| efectos_de_copper.md | Degradados, paletas por zona, splits, *copper chunky*. |
| interfaz_de_usuario.md | `eng::ui`: widgets, layout, entrada. |

> El conjunto **crece por tarea**; cada guía nueva se añade aquí y se indexa.

Volver al [índice del manual](../README.md).
