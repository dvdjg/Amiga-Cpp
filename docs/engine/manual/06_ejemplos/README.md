# Ejemplos

**Código funcional** completo, organizado por tema. Cada ejemplo es un programa real (o el enlace a
una **demo** del repo) que compila y se ejecuta en WinUAE, con su validación (READY + Ollama/asserts).

| Tema | Ejemplo / demo |
|---|---|
| Juego mínimo | `demos/features/engine/amiga/…` (fachada `App`) |
| Framebuffer indexado | `demos/features/engine/amiga/061_indexed_display` |
| Sprites | `demos/features/engine/amiga/062_sprite_scene` |
| Scroll de tiras | `demos/techniques/amiga/playfield/204_app_strip_scroll` |
| Corkscrew 8-way | `demos/techniques/amiga/playfield/107_xlimited_corkscrew` |
| Split-screen por el `App` | `demos/techniques/amiga/playfield/131_app_split_screen` |
| Recursos y `.engz` | `demos/techniques/amiga/io/212_zone_resources` |

> Los ejemplos **enlazan** a las demos; no se copia su código (una sola verdad). Ver también
> `docs/demos/` y el `README.md` de cada demo.

Volver al [índice del manual](../README.md).
