## Build / run / analyze

```bash
bash ./tools/build/build-demo.sh demos/techniques/amiga/effects/<NNN>_<tema> --debug --clean
bash ./tools/run/run-demo.sh demos/techniques/amiga/effects/<NNN>_<tema>
bash ./tools/analyze/analyze-demo.sh demos/techniques/amiga/effects/<NNN>_<tema>
```

El número `NNN` es único **dentro de este ámbito** (`demos/techniques/amiga/effects`).
