# HOST-424 — separación armónica experimental

Comprueba el primer separador host reproducible sobre una mezcla sintética: busca candidatos de frecuencia fundamental en una rejilla, estima la energía de varios armónicos mediante DFT directa y construye modelos de pistas aditivas.

El algoritmo es una base de evaluación, no una separación instrumental general. Todavía necesita seguimiento de notas por ventanas, asignación estable de candidatos, residual y selección por recomposición perceptual sobre grabaciones reales.
