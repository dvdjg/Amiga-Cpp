# HOST-425 — prototipos espectrales tiempo-frecuencia

Comprueba la separación host mediante STFT, diccionario de prototipos espectrales, activación temporal y desplazamiento de bins por frame. Verifica que cada prototipo tiene una muestra temporal exportable, que el writer puede crear un ACP1 compacto con unidades compartidas y que la variante de ocho prototipos no empeora el residual frente a la variante de tres sobre una mezcla sintética determinista.
